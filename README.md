# 📄 Interactive CV Website

A responsive online CV built using **HTML5** and **CSS3** to present my education, work experience, skills, and professional background in a clean and modern format.

---

## 📌 Project Overview

This project was created to transform a traditional resume into a web-based format that is accessible, responsive, and visually appealing.

The website showcases:

* Professional profile
* Education
* Work experience
* Technical skills
* Languages
* Contact information

---

## 🚀 Features

* Responsive design
* Clean and modern layout
* Structured professional information
* Semantic HTML
* Custom CSS styling
* Mobile-friendly interface

---

## 🛠 Technologies Used

* HTML5
* CSS3
